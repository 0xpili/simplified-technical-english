# Quick reference

This file is a short checklist of the STE rules.
Use it when you examine a text.

The full rules are in `references/writing-rules.md`.

## Words

- [ ] Use only approved words, technical names, and technical verbs.
- [ ] Use each approved word as the correct part of speech.
- [ ] Use each approved word with its approved meaning.
- [ ] Use one name for one item in the full text.
- [ ] Write noun clusters of maximum three words.
- [ ] Do not use a technical name as a verb.
- [ ] Do not make a phrasal verb.
- [ ] Use American English spelling.

## Verbs

- [ ] Use only the infinitive, the imperative, the simple present, the simple past, the future with "will", and the past participle as an adjective.
- [ ] Use the active voice.
- [ ] Do not use a helping verb with a past participle.
- [ ] Use only "can", "must", and "will" as helping verbs.
- [ ] Use the "-ing" form only in a technical name or in a title.
- [ ] In a procedure, use the imperative.

## Sentences

- [ ] A procedural sentence has maximum 20 words.
- [ ] A descriptive sentence has maximum 25 words.
- [ ] A paragraph has maximum 6 sentences and one topic.
- [ ] Write one instruction in each sentence.
- [ ] Write one topic in each sentence.
- [ ] Put a comma after a condition that comes before a command.
- [ ] Keep the articles, the subjects, the verbs, and the "that".
- [ ] Do not use a contraction.
- [ ] Do not use a semicolon.
- [ ] Use a vertical list for complex text.

## Safety

- [ ] Use "WARNING" for a risk of injury or death to persons.
- [ ] Use "CAUTION" for a risk of damage to objects.
- [ ] Start with a command or a condition. Then give the risk.
